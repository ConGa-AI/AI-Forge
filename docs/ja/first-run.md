# 初めて使う

左の順に進めてください。接続設定 →（任意）データ設定 → Agents。

## ユーザー名を保存する

**接続設定** で、管理者から指定されたユーザー名を保存します。

## このパソコンを許可する

![接続の許可](../assets/authorize.png)

**接続の許可** を押し、**鍵をコピー** で一行まるごと管理者へ渡します。

## 接続してサービス鍵を貼る

![接続設定](../assets/connection.png)

**接続** を押し、「接続成功」になったらサービス鍵を貼って **保存して確認** します。

そのあと **Agents** から起動します。詳細は [Agents](agents.md)。
