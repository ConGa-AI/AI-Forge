# 初めて使う

左の順に進めてください。接続設定 → Agents。システム状態が次の一歩を示します。データ設定と MCP は鍵が通ってからで構いません。

## ユーザー名を保存する

**接続設定** で、管理者から指定されたユーザー名を **儲存** します。

## このパソコンを許可する

![接続の許可](../assets/authorize.png)

**連線授權** を押し、**複製金鑰** で一行まるごと管理者へ渡します。

## 接続してサービス鍵を貼る

![接続設定](../assets/connection.png)

**連線** を押し、「連線成功」になったらサービス鍵を貼って **儲存並驗證** します。「對話服務」と「向量化服務」が可用になり、「向量維度」が出ます。保存済みなら **重新驗證**。

## ベクトルデータベース（推奨）

初回に「安裝本機向量資料庫？」と出ることがあります。**安裝**、**稍後**、**略過** を選べます。あとからデータ設定の **安裝並啟動** でも入れられます。

## 最初のアシスタント

**Agents** で助手を選び、**加入資料夾** のあとフォルダー名か **啟動**。詳細は [Agents](agents.md)。

## MCP とデータ管理（任意）

鍵が通ったら **MCP** で **本機文件庫** をオンにできます。本機ブラウザーが必要なら **瀏覽器操作**（Browser Use MCP）をダウンロードしてスイッチを入れ、**一鍵套用到 Agents**。次の起動から使えます。詳細は [MCP](mcp.md)。

文書の取り込みは [データ設定](data.md) のあと [データ管理](library.md) です。
