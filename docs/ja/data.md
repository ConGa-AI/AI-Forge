# データ設定

![データ設定](../assets/data.png)

見出しは **向量資料庫** と **資料格式模組** です。未安裝なら **安裝並啟動**。準備できたあとのごみ箱は **一鍵移除** で、インストールとこのパソコンのデータセットをまとめて消します。取り消せません。

形式は使う種類だけオン。**文字與 Markdown** は **內建** で外せません。

| モジュール | 画面の拡張子 |
|---|---|
| 文字與 Markdown | `.txt`、`.md`、`.markdown`、`.rst`、`.log` |
| 程式碼與設定檔 | `.go`、`.py`、`.ts` など |
| 表格資料 | `.csv`、`.tsv` |
| PDF 文件 | `.pdf` |
| Office 文件 | `.docx`、`.pptx`、`.xlsx` |
| 電路板圖檔 | `.gbr`、`.gtl` など |

準備ができたら [データ管理](library.md) へ。
