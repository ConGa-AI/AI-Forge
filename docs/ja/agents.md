# Agents

![Agents](../assets/agents.png)

アシスタントを入れ、最近使ったプロジェクトからすばやく起動します。一覧は最大 10 件のショートカットです。クリックすると新しいウィンドウが開きます。進行中かどうかは出ません。

| アシスタント | 用途 |
|---|---|
| OpenCode | 一般的なコーディング |
| Claude Code | 会話でプロジェクトを直す |
| Codex | コードの作成と修正 |
| Grok Build | 公式手順のコーディング助手 |
| Hermes Agent | 端末で長めの作業をする助手 |
| Pi | プロジェクトフォルダーでファイルを直す、小さめの助手 |

未安裝なら **一鍵安裝**。公式手順は **開啟說明文件**。入れたら **我已安裝，重新偵測**。Node.js は 22 以上。

カードのごみ箱は **一鍵移除** です。その助手のダウンロードと、このアプリが書いた設定だけ消えます。プロジェクトや他の助手は残ります。

**加入資料夾** でフォルダーを足し、名前をクリックするか **啟動**。一覧のごみ箱はショートカットだけ消します。
