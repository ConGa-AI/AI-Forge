# 接続設定

![接続設定](../assets/connection.png)

**身分 → 連線 → 金鑰** の三段です。

![接続の許可](../assets/authorize.png)

**複製金鑰** を使い、管理者の許可が終わってから **連線** します。接続成功後にサービス鍵を **儲存並驗證** してください。「對話服務」「向量化服務」「向量維度」が出ます。保存済みなら **重新驗證**。

一時的に切るときは **中斷連線**。未授權・遠端無法連線・伺服器驗證失敗のときは、管理者へ連絡するかネットワークを確認して **重試** します。
