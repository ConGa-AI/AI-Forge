# 接続設定

![接続設定](../assets/connection.png)

**名前 → 接続 → 鍵** の三段です。

![接続の許可](../assets/authorize.png)

**鍵をコピー** を使い、管理者の許可が終わってから **接続** します。接続成功後にサービス鍵を保存して確認してください。
