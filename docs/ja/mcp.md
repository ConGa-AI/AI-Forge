# MCP

![MCP](../assets/mcp.png)

この画面は、この鍵が通路で使えるツールを調べ、本機ツールと通路のサービスを Agents の設定へ書きます。接続成功とサービス鍵の保存が先です。

| ボタン | 役割 |
|---|---|
| **重新偵測** | 通路の一覧を取り直す |
| **一鍵套用到 Agents** | オンになっている項目を助手の設定へ書く。**次の起動**から使います |

**本機文件庫** はタグが **本機**。このパソコンに取り込んだ文書を検索します。ベクトルデータベースが準備できて、[データ管理](library.md) にファイルがあるとき、起動した助手が使えます。

**瀏覽器操作**（横に **Browser Use MCP**、**可選**）は任意です。**下載並安裝** → 「已下載，可以啟用」になってからスイッチ → **一鍵套用到 Agents** → 助手を起動し直します。ごみ箱の **一鍵移除** はこのツールのインストールだけ消します。Node.js 22 以上が必要な場合があります。

**通道服務** は鍵の権限で変わります。使えない項目は **金鑰無權限** です。全員同じ一覧ではありません。
