# データ管理

![データ管理](../assets/library.png)

左でデータセットを選び、右で取り込み、ファイルは**一覧**です。

「新增資料集」に名前を入れて **新增**。赤い **刪除** はデータセット全体です。幅は通路の向量化サービスが決め、自分では変えません。

取り込みは **加入檔案**（選擇檔案）→ **開始匯入**。四段は **解析中** → **理解圖片** → **向量化** → **寫入中**。

![文書の内容](../assets/library-view.png)

行をクリックすると **文件內容** が開きます。段落を **搜尋** し、**搜尋用文字** を見ます。原文が違うときだけ **原文** が出ます。プレビューできない形式は位置だけ示します。**刪除文件** はそのファイルの段落だけ消します。

取り込んだら [MCP](mcp.md) で本機文件庫をオンにして適用し、[Agents](agents.md) から聞きます。
