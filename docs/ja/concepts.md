# かんたんな考え方

先に言葉を揃えておくと、あとの画面が分かりやすくなります。[システム状態](status.md) や [接続設定](connection.md) へいつでも戻ってください。

通路は、このパソコンからサービスへ向かう専用の道です。許可用の鍵（連線授權 → 複製金鑰）とサービス鍵は別物です。

検証では **對話**（問答・コード）と **向量化**（ファイルを検索できる意味にする）を見ます。画面の「向量維度」は取り込みに使います。自分で数値を入れる欄はありません。

ベクトルデータベースはこのパソコンの中にあります。バッジは「向量庫」、準備項目は「資料庫」、データ設定の見出しは「向量資料庫」。**一鍵移除** はインストールとデータセットをまとめて消します。

データセットは名前の付いた箱です。アシスタントは選んだフォルダーで新しいウィンドウとして開きます。画面上の六つは OpenCode、Claude Code、Codex、Grok Build、Hermes Agent、Pi です。最近プロジェクトは最大 10 件のショートカットです。

MCP は起動時に助手へ渡すツールです。**本機文件庫**、任意の **瀏覽器操作**、通路側のサービス。**一鍵套用到 Agents** のあとは、次の起動から効きます。
