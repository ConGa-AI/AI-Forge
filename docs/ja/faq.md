# よくある質問

開かないときは、実行の許可（Windows／Mac／Linux）を確認してください。未許可と出たら、鍵をまるごとコピーし直します。灰色のボタンは、[システム状態](status.md) の次の一歩に従ってください。MCP はサービス鍵の保存も必要です。

一鍵安裝が動かないときは Node.js 22 以上を入れてアプリを開き直します。終わっているのに未安裝なら、いったん終了して **我已安裝，重新偵測**。

最近プロジェクトのごみ箱はショートカットだけです。Agents の **一鍵移除** はその助手のダウンロードと、このアプリが書いた設定だけです。向量資料庫の **一鍵移除** はインストールと全データセットを消します。ファイル一つならデータ管理の **刪除文件** です。

瀏覽器操作は先に **下載並安裝** し、「已下載，可以啟用」になってからスイッチ、**一鍵套用到 Agents**、助手を起動し直します。

この説明の言語は、各ページ上部のリンクで切り替えられます。
