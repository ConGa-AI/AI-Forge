![系統狀態](../assets/status.png)

## 這套工具能做什麼

| 你想做的事 | 去哪個畫面 |
|---|---|
| 看現在能不能開始工作 | 系統狀態 |
| 授權這台電腦、連上通道、貼上服務金鑰 | 連線設定 |
| 安裝並啟動 OpenCode、Codex、Grok Build、Claude Code | Agents |
| 在這台電腦安裝本機資料庫、打開需要的檔案格式 | 資料設定 |
| 建立資料集、把文件匯進去 | 資料管理 |

## 第一次走完這四步就夠了

1. 儲存使用者名稱，複製授權金鑰交給管理員。
2. 連線成功後，貼上服務金鑰並驗證。
3. （建議）安裝本機資料庫。
4. 選一個 Agent、加入專案資料夾、點一下即可啟動。

下載請到 [最新發行頁](https://github.com/ConGaAI/AI-Forge-SRC/releases/latest)。
