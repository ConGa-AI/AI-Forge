# AI Forge 使用說明

![系統狀態](../assets/status.png)

這份說明只講怎麼用。選你的電腦、完成第一次設定，就能在專案資料夾裡啟動助手，也可以把文件放進本機資料庫供之後搜尋，並把本機工具寫進助手設定。

## 這套工具能做什麼

| 你想做的事 | 去哪個畫面 |
|---|---|
| 看現在能不能開始工作 | 系統狀態 |
| 授權這台電腦、連上通道、貼上服務金鑰 | 連線設定 |
| 安裝並啟動 OpenCode、Claude Code、Codex、Grok Build、Hermes Agent、Pi | Agents |
| 把本機文件庫、瀏覽器操作與通道工具寫進助手設定 | MCP |
| 在這台電腦安裝向量資料庫、打開需要的檔案格式 | 資料設定 |
| 建立資料集、匯入文件、檢視或刪除單一文件 | 資料管理 |

## 第一次走完這四步就夠了

1. 儲存使用者名稱，複製授權金鑰交給管理員。
2. 連線成功後，貼上服務金鑰並驗證。
3. （建議）安裝本機向量資料庫。
4. 選一個 Agent、加入專案資料夾、點一下即可啟動。

金鑰通過後，可再到 [MCP](mcp.md) 啟用本機文件庫或下載瀏覽器操作。左側六個畫面可用數字鍵 `1`–`6` 切換。

下載請到 [最新發行頁](https://github.com/ConGa-AI/AI-Forge-SRC/releases/latest)。
