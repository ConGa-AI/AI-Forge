# 資料管理

![資料管理](../assets/library.png)

把文件放進資料集之後，啟動的助手才能搜尋這些內容。

尚未連線、金鑰未通過向量化驗證、或本機資料庫未就緒時，畫面會列出要先完成的步驟，並可直接跳過去。

## 新增資料集

1. 輸入名稱，例如 `product-docs`。
2. 按 **新增**。

維度由通道上的向量化服務決定，畫面上沒有可改的欄位。若之後金鑰對應的服務變了，請改用新的資料集。

## 匯入檔案

1. 選 **目標資料集**。
2. 按 **選擇檔案**。
3. 按 **開始匯入**。

進度大致是：解析 → 向量化 → 寫入。一次可以選多個檔。某個檔失敗時，其他檔仍可能成功。

## 給助手用時

匯入完成後不必再做額外設定。到 [Agents](agents.md) 啟動助手，用平常說話的方式問即可。
