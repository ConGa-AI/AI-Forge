# 系統狀態

![系統狀態](../assets/status.png)

這個畫面回答一件事：**現在能不能開始工作**。

## 建議下一步

頁面上方的綠色提示會指出目前最該做的事，例如連上通道、驗證金鑰、安裝本機資料庫，或選一個 Agent 並啟動。點它就會跳到對應畫面。

## 就緒程度

四個項目都亮起，代表這台電腦已準備好完整功能：

| 項目 | 意思 |
|---|---|
| 通道 | 已經連上 |
| 對話 | 服務金鑰可用於問答與寫程式 |
| 向量化 | 可以把文件轉成可搜尋的意義 |
| 資料庫 | 本機資料庫已就緒 |

## 連線檢查

下方三項是即時健康檢查：遠端入口、本機通道、向量資料庫。若剛連上或剛安裝完，可按 **重新檢查**。
