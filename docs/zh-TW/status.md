# 系統狀態

![系統狀態](../assets/status.png)

這個畫面回答一件事：**現在能不能開始工作**。

## 建議下一步

頁面上方的綠色區塊會指出目前最該做的事。四項都就緒時，標題是「系統就緒，可以開始工作」，內文仍會引導你「選一個 Agent，在專案資料夾啟動」。點它會跳到 Agents。

尚未就緒時，可能是：連上通道、儲存並驗證服務金鑰、安裝本機向量資料庫。

## 就緒程度

四個項目都亮起，代表這台電腦已準備好完整功能（MCP 不在這四項裡，金鑰通過後另開 MCP 頁）：

| 畫面上的名稱 | 意思 |
|---|---|
| 通道 | 已經連上 |
| 對話 | 服務金鑰可用於問答與寫程式 |
| 向量化 | 可以把文件轉成可搜尋的意義 |
| 資料庫 | 本機向量資料庫已就緒 |

點每一項也可以跳過去。

## 連線檢查

下方三項是即時健康檢查：**遠端入口**、**本機通道**、**向量資料庫**。若剛連上或剛安裝完，可按 **重新檢查**。

視窗最上方也有「連線成功」與「向量庫 就緒」這類徽章，任何畫面都能看到目前狀態。
