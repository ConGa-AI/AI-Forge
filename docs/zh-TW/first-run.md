# 第一次使用

建議依畫面左側順序走：連線設定 → Agents。系統狀態頁會告訴你下一步。資料設定與 MCP 可在金鑰通過後再補。

## 1. 填使用者名稱

1. 打開 **連線設定**。
2. 輸入管理員給你的使用者名稱。
3. 按 **儲存**。

名稱不對時，後面連線會失敗。

## 2. 授權這台電腦

![連線授權](../assets/authorize.png)

1. 按 **連線授權**。
2. 按 **複製金鑰**（一定要複製完整一行，不要用手選畫面上被省略的文字）。
3. 把這一行交給管理員。
4. 管理員完成授權後再回到應用程式。

## 3. 連線並貼上服務金鑰

![連線設定](../assets/connection.png)

按 **連線**。狀態變成「連線成功」即可。

1. 在「服務金鑰」貼上管理員給你的金鑰。
2. 按 **儲存並驗證**。

成功時，「對話服務」與「向量化服務」都會顯示可用，並出現「向量維度」。金鑰會自動帶進之後啟動的助手。已存過金鑰時可按 **重新驗證**。

若顯示「未授權」，代表管理員還沒放行，或你複製的不是完整金鑰。若顯示「遠端無法連線」，請檢查網路後按 **重試**。

## 4. 安裝本機向量資料庫（建議）

第一次可能會跳出「安裝本機向量資料庫？」。選 **安裝** 即可；也可以 **稍後** 或 **略過**。之後仍可在 **資料設定** 按 **安裝並啟動**。

略過後仍可啟動助手，只是不能建立資料集、也不能把文件匯進去。

## 5. 啟動第一個助手

打開 **Agents**，選一個助手，按 **加入資料夾**，點資料夾名稱或右側 **啟動**。細節見 [Agents](agents.md)。

## 6. （可選）MCP 與資料管理

金鑰通過後可打開 **MCP**：預設可啟用 **本機文件庫**；若要讓助手開本機瀏覽器讀網頁，在 **可選本機工具** 把 **瀏覽器操作** 下載後打開開關，再按 **一鍵套用到 Agents**。下次啟動助手才會用到新設定。細節見 [MCP](mcp.md)。

匯入文件請先到 [資料設定](data.md) 確認向量資料庫就緒，再到 [資料管理](library.md)。
