# Agents

![Agents](../assets/agents.png)

這裡用來安裝助手，並從最近的專案資料夾快速啟動。清單最多 10 筆，純粹是捷徑：點一下就開新視窗，不會顯示「進行中」，也不負責關閉那個視窗。

尚未連線時，畫面會提示先完成連線，並可跳回 [連線設定](connection.md)。

## 選擇助手

卡片順序與畫面上一致：

| 助手 | 說明 |
|---|---|
| OpenCode | 泛用程式助手，適合多數專案 |
| Claude Code | 以對話方式改專案 |
| Codex | 以寫程式、改程式為主 |
| Grok Build | 另一種寫程式助手，走官方安裝方式 |
| Hermes Agent | 終端裡的自主型助手，適合較長的工作 |
| Pi | 精簡的程式助手，在專案資料夾裡改檔 |

選中後，若顯示「未安裝」，請先安裝再啟動。已安裝的卡片右上有垃圾桶，那是 **一鍵移除**。

## 安裝助手

1. 選卡片。
2. 若支援，按 **一鍵安裝** 並等進度跑完。
3. 也可 **開啟說明文件** 依官方步驟安裝。
4. 裝好後按 **我已安裝，重新偵測**。

若提示找不到 Node.js，請先在這台電腦安裝 Node.js 22 或更新版本，再開一次 AI Forge 後重試。部分助手安裝完成後需要先關掉 AI Forge 再打開。

## 一鍵移除

按卡片上的垃圾桶後會再確認一次。確定後會刪除：安裝時下載的程式，以及本應用為這個助手寫入的設定。無法復原。

不會刪：專案資料夾、連線用的設定檔、SSH 金鑰、其他助手、這台電腦上共用的 Node.js。

## 最近專案

1. 按 **加入資料夾**，選本機專案。清單上方可以搜尋名稱。
2. 點資料夾名稱，就會用目前選中的助手在該目錄啟動。
3. 右側 **啟動** 則啟動目前標成「使用中」的那一筆。
4. 垃圾桶只是把捷徑從清單拿掉，不會刪你磁碟上的專案。
