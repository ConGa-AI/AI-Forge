# 幾個簡單觀念

先花兩分鐘看這些詞，後面的畫面會比較好懂。可隨時跳回 [系統狀態](status.md) 或 [連線設定](connection.md)。

## 通道

通道是這台電腦連到服務的一條專用小路。連上之後，對話與向量化都走這條路，不會把你的金鑰散落在各個助手設定裡。

還沒連上時，助手與資料功能會先請你完成連線。

## 兩把不一樣的金鑰

| | 授權金鑰 | 服務金鑰 |
|---|---|---|
| 用途 | 證明「這台電腦可以使用通道」 | 證明「你可以使用對話與向量化」 |
| 從哪來 | 應用程式畫面產生，請複製完整一行 | 由管理員發給你 |
| 給誰看 | 交給管理員完成授權 | 只貼在「連線設定」裡 |

請不要把兩把金鑰搞混，也不要把畫面上被省略的授權金鑰片段拿去交給管理員——一定要按「複製金鑰」。

## 對話與向量化

驗證服務金鑰時，畫面會檢查兩件事（系統狀態上寫成「對話」「向量化」；連線設定上寫成「對話服務」「向量化服務」）：

- **對話**：能不能正常問答、寫程式。
- **向量化**：能不能把文件轉成「可搜尋的意義」，而不是只能用關鍵字對字。

兩者都可用，資料匯入與本機搜尋才完整。畫面也會顯示「向量維度」，匯入時會用到，你不必自己填。

## 本機向量資料庫

這是裝在**你這台電腦**上的私人資料庫。頂部徽章寫「向量庫」，系統狀態就緒項目寫「資料庫」，資料設定卡片標題是「向量資料庫」。資料不會因為你換了一個 Agent 就消失。

第一次使用時可以安裝、稍後再說，或略過。略過後仍可啟動助手，只是不能建立資料集、也不能把文件匯進去。

在資料設定按 **一鍵移除** 會刪掉安裝檔，以及這台電腦上的資料集，無法復原。

## 資料集

資料集像一個有名字的盒子，例如「產品說明」。匯入檔案時要指定放進哪一個。之後在助手裡提問，它才能從對的盒子找內容。資料管理左側選資料集，右側是檔案清單。

## Agent 與專案資料夾

Agent 是實際幫你寫程式、改檔案的助手。AI Forge 不會把助手嵌在同一個小視窗裡，而是在**新視窗**打開，並且工作目錄就是你選的專案資料夾。

畫面上目前有六個：OpenCode、Claude Code、Codex、Grok Build、Hermes Agent、Pi。

「最近專案」只是快捷清單：點一下就用目前選中的 Agent 啟動，最多記住 10 筆。清單**不會**顯示進行中，也不負責關掉那個視窗。垃圾桶只移除捷徑。

助手卡片上的 **一鍵移除** 只刪該助手安裝時下載的程式，以及本應用為它寫入的設定；不會刪專案、不會刪 `config.json`、也不會刪其他助手。

## MCP

MCP 頁把助手啟動時能用的工具寫進設定：**本機文件庫**搜尋這台電腦已匯入的文件；**瀏覽器操作**（畫面上另標 Browser Use MCP）可選下載，讓助手開本機瀏覽器讀畫面；其餘項目來自通道、依金鑰權限顯示。按 **一鍵套用到 Agents** 後，要等**下次啟動**才生效。
