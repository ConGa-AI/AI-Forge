# 幾個簡單觀念

先花兩分鐘看這些詞，後面的畫面會比較好懂。可隨時跳回 [系統狀態](status.md) 或 [連線設定](connection.md)。

## 通道

通道是這台電腦連到服務的一條專用小路。連上之後，對話與文件理解都走這條路，不會把你的金鑰散落在各個助手設定裡。

還沒連上時，助手與資料功能會先請你完成連線。

## 兩把不一樣的金鑰

| | 授權金鑰 | 服務金鑰 |
|---|---|---|
| 用途 | 證明「這台電腦可以使用通道」 | 證明「你可以使用對話與文件理解」 |
| 從哪來 | 應用程式畫面產生，請複製完整一行 | 由管理員發給你 |
| 給誰看 | 交給管理員完成授權 | 只貼在「連線設定」裡 |

請不要把兩把金鑰搞混，也不要把畫面上被省略的授權金鑰片段拿去交給管理員——一定要按「複製金鑰」。

## 對話與向量化

驗證服務金鑰時，畫面會檢查兩件事：

- **對話**：能不能正常問答、寫程式。
- **向量化**：能不能把文件轉成「可搜尋的意義」，而不是只能用關鍵字對字。

兩者都可用，資料匯入與本機搜尋才完整。

## 本機資料庫

這是裝在**你這台電腦**上的私人資料庫，用來保存匯入後的文件意義，方便之後搜尋。資料不會因為你換了一個 Agent 就消失。

第一次使用時可以安裝、稍後再說，或略過。略過後仍可啟動助手，只是不能建立資料集、也不能把文件匯進去。

## 資料集

資料集像一個有名字的盒子，例如「產品說明」或「專案規格」。匯入檔案時要指定放進哪一個盒子。之後在助手裡提問，它才能從對的盒子找內容。

## Agent 與專案資料夾

Agent 是實際幫你寫程式、改檔案的助手。AI Forge 不會把助手嵌在同一個小視窗裡，而是在**新視窗**打開，並且工作目錄就是你選的專案資料夾。

「最近專案」只是快捷清單：點一下就用目前選中的 Agent 啟動，最多記住 10 筆。清單**不會**顯示進行中，也不負責關掉那個視窗。
