# 資料設定

![資料設定](../assets/data.png)

這個畫面管兩件事：這台電腦上的**本機資料庫**，以及這台電腦**讀得懂哪些檔案**。

## 本機向量資料庫

對使用者來說就是：把文件變成可搜尋的私人資料庫，而且只存在這台電腦。

| 狀態 | 你可以做什麼 |
|---|---|
| 未安裝 | 按「安裝並啟動」 |
| 安裝中／啟動中 | 等進度結束 |
| 就緒 | 可以去 [資料管理](library.md) 建立資料集 |
| 已停止 | 再按一次安裝並啟動 |
| 失敗 | 按重試；仍不行請重開應用程式後再試 |

略過安裝時，助手仍可啟動，但不能匯入文件。

## 資料格式模組

只打開你真的會匯入的格式即可。內建「文字與 Markdown」不能關閉。

| 模組 | 適合什麼檔 |
|---|---|
| 文字與 Markdown | `.txt`、`.md` 等 |
| 程式碼與設定檔 | 常見原始碼與設定 |
| 表格資料 | `.csv` 等 |
| PDF 文件 | `.pdf` |
| Office 文件 | Word／簡報等 |
| 電路板圖檔 | 相關工程圖檔 |
