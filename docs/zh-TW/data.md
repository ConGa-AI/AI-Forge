# 資料設定

![資料設定](../assets/data.png)

這個畫面管兩件事：這台電腦上的**向量資料庫**，以及這台電腦**讀得懂哪些檔案**。

## 向量資料庫

卡片標題是「向量資料庫」。對使用者來說就是：把文件變成可搜尋的私人資料，而且只存在這台電腦。

| 狀態 | 你可以做什麼 |
|---|---|
| 未安裝 | 按 **安裝並啟動** |
| 安裝中／啟動中 | 等進度結束 |
| 就緒 | 可以去 [資料管理](library.md) 建立資料集 |
| 已停止 | 再按一次安裝並啟動 |
| 失敗 | 按重試；仍不行請重開應用程式後再試 |

略過安裝時，助手仍可啟動，但不能匯入文件。

就緒後卡片右側的垃圾桶是 **一鍵移除**。確認文案會說明：安裝檔與這台電腦上的資料集都會刪除，無法復原。這與 Agents 的一鍵移除不同，後者不會動資料集。

## 資料格式模組

只打開你真的會匯入的格式即可。內建「文字與 Markdown」不能關閉，徽章為 **內建**。其他模組用開關安裝或移除。

| 模組 | 畫面列出的副檔名 |
|---|---|
| 文字與 Markdown | `.txt`、`.md`、`.markdown`、`.rst`、`.log` |
| 程式碼與設定檔 | `.go`、`.py`、`.js`、`.ts` 等常見原始碼與設定 |
| 表格資料 | `.csv`、`.tsv` |
| PDF 文件 | `.pdf` |
| Office 文件 | `.docx`、`.pptx`、`.xlsx` |
| 電路板圖檔 | `.gbr`、`.gtl` 等層檔 |

匯入尚未安裝的格式時，資料管理會提示到這裡安裝模組。
