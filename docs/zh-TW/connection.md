# 連線設定

![連線設定](../assets/connection.png)

這個畫面分三段：**身分 → 連線 → 金鑰**。請依序完成。

## 使用者名稱

輸入管理員指定的名稱後按 **儲存**。這是這台電腦在通道上的身分。

## 連線授權

![連線授權](../assets/authorize.png)

按 **連線授權** 會看到這台電腦的授權金鑰。請按 **複製金鑰**，不要用手去選畫面上被截短的文字。把完整一行交給管理員，授權完成後再按 **連線**。

## 連線按鈕

| 你看到的狀態 | 建議 |
|---|---|
| 未連線 | 確認名稱已儲存、授權已完成，再按連線 |
| 連線中／重新連線中 | 稍候；網路不穩時會自動再試 |
| 連線成功 | 可以貼服務金鑰 |
| 未授權 | 請管理員再確認是否已放行這台電腦 |
| 遠端無法連線 | 檢查網路後按重試 |
| 伺服器驗證失敗 | 請聯絡管理員，不要自行忽略 |

需要暫時離開時可按 **中斷連線**。

## 服務金鑰

連線成功後才能驗證。貼上金鑰後按 **儲存並驗證**。畫面會分別顯示對話服務、向量化服務是否可用，以及向量維度（匯入時會用到，你不必自己填）。
