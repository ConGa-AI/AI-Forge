# First-time setup

Follow the left-hand order: Connection → Agents. The Status screen also points to the next step. Data setup and MCP can wait until the key works.

## 1. Save your username

Open **Connection**, enter the username your administrator gave you, and click **Save**.

## 2. Authorize this computer

![Authorize](../assets/authorize.png)

Click **Authorize**, then **Copy key** (the full line). Send it to your administrator. Come back after they have approved this computer.

## 3. Connect and paste the service key

![Connection](../assets/connection.png)

Click **Connect**. You want the status **Connected**. Paste the service key and click **Save & verify**. **Answering** and **Vectorizing** should both show **Available**, with **Vector width** filled in. If a key is already stored, use **Verify again**.

## 4. Install the local vector database (recommended)

A prompt may appear the first time: **Install a local vector database?** Choose **Install**, or **Later** / **Never**. You can still click **Install & start** on **Data setup**.

If you skip, assistants still launch, but you cannot create datasets or import files.

## 5. Launch your first assistant

Open **Agents**, pick an assistant, click **Add folder**, then click the folder name or **Launch**. See [Agents](agents.md).

## 6. (Optional) MCP and the data library

After the key works, open **MCP**. **Local library** can be turned on immediately. For a local browser, download **Browser control** (labelled **Browser Use MCP**), enable it, then click **Apply to agents**. The next launch picks it up. Details: [MCP](mcp.md).

Import files from [Data setup](data.md) then [Data library](library.md).
