# Agents

![Agents](../assets/agents.png)

Install an assistant and launch it from recent project folders. The list keeps at most 10 shortcuts. Click to open a new window. It does not show in-progress work.

| Assistant | Typical use |
|---|---|
| OpenCode | General coding assistant for most projects |
| Claude Code | Conversational edits in a project |
| Codex | Focused on writing and changing code |
| Grok Build | Another coding assistant with its official installer |
| Hermes Agent | A terminal agent for longer autonomous work |
| Pi | A small coding assistant that edits files in the project folder |

If the card says **not installed**, install before launch. Prefer **Install now**. Installed cards show a trash control titled **Remove**.

## Install

1. Select a card.
2. If supported, click **Install now** and wait.
3. Or **Open docs** for the official steps.
4. Then **I installed it — recheck**.

If it asks for Node.js, install Node.js 22 or newer, reopen AI Forge, and try again. Some assistants need you to quit AI Forge and open it again after install.

## Remove an assistant

**Remove** deletes the downloaded program and settings this app wrote for that assistant. It does not delete your project, the app configuration, SSH keys, or other assistants.

## Recent projects

1. Click **Add folder** and pick a local project. You can search folder names above the list.
2. Click the folder name to launch the selected assistant in that directory.
3. **Launch** on the right starts the folder marked **Active**.
4. The trash can only removes the shortcut.
