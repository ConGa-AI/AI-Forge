# FAQ

**The download will not open.** Allow this run (Windows), Privacy & Security (Mac), or run as a program (Linux).

**Connect says unauthorized.** Copy the full authorization key again and resend it.

**The service key fails.** Make sure the channel shows Connected, then paste the **service key**, not the authorization key.

**Why are some actions greyed out?** Follow **Next step** on [Status](status.md).

**Does removing a project from the list delete my files?** No.

This guide can switch language from the bar at the top of every page.
