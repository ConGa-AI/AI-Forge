# FAQ

**The download will not open.** Allow this run (Windows), Privacy & Security (Mac), or run as a program (Linux).

**Connect says unauthorized.** Copy the full authorization key again and resend it.

**The service key fails.** Make sure the channel shows Connected, then paste the **service key**, not the authorization key. Use **Verify again** if a key is already stored.

**Why are some actions greyed out?** Follow **Next step** on [Status](status.md). MCP also needs a saved service key.

**Install now does nothing / still not installed.** Install Node.js 22 or newer and reopen AI Forge. If the installer already finished, quit the app, open it again, then **I installed it — recheck**.

**Clicking a folder does not open a new window.** Confirm you are connected, the assistant shows **Installed**, and a project folder is selected. Try **Launch**.

**Does removing a project from the list delete my files?** No. Trash only removes the shortcut.

**What does Remove on an agent card delete?** Only that assistant’s downloaded program and settings this app wrote. Projects and other assistants stay.

**What does Remove on the vector database delete?** The install and **every dataset** on this computer. To drop one file, use **Delete document** on Data library.

**Browser control will not enable.** Download it first until it says **Downloaded — ready to enable**. Then apply to agents and relaunch the assistant. Node.js 22 or newer may be required.

**Why is there no in-progress state?** The list is at most 10 shortcuts for launch only.

This guide can switch language from the bar at the top of every page.
