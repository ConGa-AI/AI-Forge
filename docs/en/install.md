# Install and download

Get the file that matches your computer from the [latest release page](https://github.com/ConGaAI/AI-Forge-SRC/releases/latest).

| Your computer | Download this file |
|---|---|
| Windows | `ai-forge-windows-amd64.exe` |
| Mac (Apple silicon) | `ai-forge-darwin-arm64` |
| Typical Linux PC | `ai-forge-linux-amd64` |
| ARM Linux | `ai-forge-linux-arm64` |

## Windows

1. Download the `.exe` file and double-click it.
2. Windows 11 usually works as-is. On Windows 10, update the system if the app will not start.

## Mac

1. Download the file and find it in Finder.
2. The first time, allow it under **System Settings → Privacy & Security**.

## Linux

1. Download the file.
2. In the file properties, allow it to run as a program.

The top of the window switches dark / light theme and Chinese / English. Continue with [first-time setup](first-run.md).
